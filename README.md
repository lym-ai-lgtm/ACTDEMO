# ACTDEMO

基于 Unreal Engine 5.8、C++、蓝图和 Gameplay Ability System（GAS）的单机动作战斗 Demo。

> 本仓库是**源码与技术文档展示版**，不是完整可运行的UE工程。蓝图、地图、模型、动画、音效和特效等 Content 资产未上传，因此克隆后不能直接运行游戏。

## 功能

- 剑与太刀两种武器，拔收刀、特殊切换攻击与技能HUD。
- 地面轻重连段、通知窗口、输入缓存与轻重变招。
- 挑飞、空中追击、轻重连击、下砸和气势强力技。
- 普通格挡、完美防御、正背面判定、气势恢复与破防。
- 锁定镜头、方向翻滚、无敌窗口与受击死亡。
- 主动敌人的绕行、连续攻击、跳斩与后撤。
- UMG主菜单、训练场拖放生成假人和主动敌人。

## 环境与资产边界

- 使用 Unreal Engine 5.8 和 Windows C++ 工具链。
- 依赖 GameplayAbilities、GameplayTags、GameplayTasks、UMG 等模块，详见 Build.cs。
- `.uproject`保留原开发项目的插件清单，其中部分插件属于编辑器自动化工具；阅读源码不需要安装它们。若自行重建工程，应按实际需求整理插件依赖。
- Config 和代码保留原工程资产路径；需要自行创建蓝图、地图并替换相关路径。
- 导入的第三方动画、武器、模型、音频和特效不在此仓库再分发。请自行合法取得素材或用自有素材替换。
- 当前以单机功能演示为目标，未完成完整多人同步验证。
